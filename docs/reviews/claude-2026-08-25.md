# Claude cross-review — 2026-08-25

This release candidate received a read-only second-model review through Claude Code using the `sonnet` alias, high effort, the `Read` tool only, safe mode, and no persisted session. The reviewer inspected the parser, rules, fixes, rewrite boundary, tests, evaluation fixtures, and public documentation. Model aliases can resolve to different dated models, so this note records the protocol and dispositions rather than claiming a timeless endorsement.

The reproducible prompt and acceptance policy live in [`docs/claude-review-protocol.md`](../claude-review-protocol.md). A maintainer independently reproduced every High finding before changing code.

## Findings and dispositions

| Area | Reproduced issue | Disposition in v0.1.0 |
|---|---|---|
| `KO-NOM-001` | `면밀한 검토를 진행했다` could become ungrammatical | downgraded to review; no text edit emitted |
| `KO-RED-001/002` | compounds, homonyms, and particles made deletion context-sensitive | downgraded to review; hard negatives added |
| `KO-SPACE-001` | names/compounds such as `철수없이`, `실수없음` could be split | compound exclusions plus a narrow safe surface allowlist |
| Parser boundaries | whitespace masks allowed regexes to bridge values, tags, code, or paragraphs | exact `proseRanges`, block-scoped regex runs, and structural-span gating |
| HTML/TSX/MDX | block grouping, internal attributes, code elements, and visible MDX props were inconsistent | block grouping and user-facing attribute allowlists added; code/import/route contexts protected |
| Suppressions | directive-looking strings in code or data could hide later prose | directives now require a real Markdown/HTML comment context |
| Rewrite boundary | a whole-document model response could move protected values or inject syntax | replaced by segment-only responses and local source reconstruction |
| Provider transport | automatic redirects could forward the key and prompt | HTTPS-by-default, `redirect: error`, timeout, content-type, and size guards |

## Residual limits

- Passing structural guards does not prove semantic equivalence; every provider result remains review-only.
- Numeric HTML character entities and NFD Hangul are not source-mapped to decoded syllables, which can reduce recall.
- Escaped JSON and JavaScript/TypeScript strings are skipped when decoded text cannot preserve exact source offsets.
- Markdown raw HTML is parsed, but complex mixed Markdown/MDX expressions are not a complete browser DOM editing surface.
- The public minimal-pair set is a release smoke benchmark, not evidence of broad genre coverage.

The candidate was re-tested after these dispositions. A second-model opinion never promotes a rule to `safe` by itself; only a reproducible invariant and regression tests can do that.
